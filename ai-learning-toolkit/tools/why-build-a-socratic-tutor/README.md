# Why Build a Socratic AI Tutor

**For:** faculty
**Platform:** slides (PPTX) and a handout (PDF)
**Status:** ready

## What it does

The evidence and architecture behind Socratic AI tutors, packaged to present or hand out. It makes the case for why a tutor that withholds answers outperforms one that supplies them, and lays out the structure that makes the difference in practice.

Two files, meant to be used together or separately:

- [`Why_Build_A_Socratic_Tutor.pptx`](Why_Build_A_Socratic_Tutor.pptx) — the deck, for a faculty development session or a departmental talk.
- [`Why_Build_A_Socratic_Tutor_Handout.pdf`](Why_Build_A_Socratic_Tutor_Handout.pdf) — the handout, which stands on its own if you would rather circulate it than present it.

## How to use it

1. Download the deck and adapt it to your audience. Swap in examples from your own course; the argument travels, the examples should be local.
2. Print or circulate the handout as a leave-behind, so the session ends with something people can act on.
3. Pair it with the [AI Tutor Creation Guide](../ai-tutor-creation-guides/README.md) if the session should end in people building something rather than just agreeing with you.
4. If you want the full topic-agnostic engine behind these tutors, the Socratic Tutor Master Template is shared directly with collaborators and training cohorts. Ask through the request form linked on the faculty page.
