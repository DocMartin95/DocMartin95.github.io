# TRACI Prompt Literacy

**For:** both students and faculty
**Platform:** a one-page reference you keep next to whatever AI tool you use
**Status:** ready

## What it does

TRACI is a five-part checklist for building a prompt that returns what you actually need: **T**ask, **R**ole, **A**udience, **C**reate, **I**ntent. Most weak AI results come from weak prompts, and most weak prompts are missing structure rather than effort. Fill in the five parts and a vague request turns into a specific one.

It is also the backbone of the tool request form on this site, which is why a plain-language request comes out well-formed.

## How to use it

1. Download [`TRACI_Prompt_Literacy.docx`](TRACI_Prompt_Literacy.docx) and keep it somewhere you can glance at.
2. Before you send a prompt, name all five parts:
   - **Task** — what you want done, as a concrete action.
   - **Role** — who the AI should act as, which sets level and stance.
   - **Audience** — who the result is for, which controls vocabulary and depth.
   - **Create** — what to produce, and in what form.
   - **Intent** — the goal, and what a good result looks like.
3. Use the copy-and-fill template at the bottom of the file for anything important.
4. If a result disappoints, find the missing letter rather than rewriting from scratch. It is usually Audience or Intent.
