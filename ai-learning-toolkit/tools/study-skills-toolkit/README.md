# Study Skills Toolkit

**For:** students
**Platform:** copy-and-paste prompts for any AI tool
**Status:** ready

## What it does

Five study tools built on one idea from learning science: you learn by producing, not by receiving. Each asks the AI to make you retrieve, explain, or plan rather than hand you answers. The set covers an adaptive practice-question generator, deep free-response practice, a wrong-answer journal, a study planner, and a fast/slow workbook.

It is subject-agnostic. Name your actual assessment in the prompt and it adapts.

## How to use it

1. Download [`Study_Skills_Toolkit.docx`](Study_Skills_Toolkit.docx) and pick the tool that matches what you need right now. Nothing depends on anything else.
2. Copy that tool's prompt into any AI assistant.
3. Fill in the bracketed parts: your course or unit, your topics with self-rated confidence, and the exam you are preparing for.
4. Answer before you read. Every prompt is written to withhold the model answer until you attempt the question, so do not skip ahead.
5. Verify what it tells you. Generate first, then check against a trusted source, because AI states wrong facts confidently.
